# SYNDICATE Академия — лендинг

Обучение покеру с нуля в Буэнос-Айресе: 8 занятий один на один + Telegram-тренажёр.
Академия закрытого клуба SYNDICATE.

**Сайт:** https://neuroba.github.io/syndicate-academia/

## Что здесь

| Файл | Что это |
|------|---------|
| `index.html` | Весь лендинг: разметка, стили и скрипты в одном файле, без сборщика и внешних библиотек |
| `og.jpg` | Картинка-превью для WhatsApp / Telegram (1200×630) |
| `foto/web/` | Фото тренера, ужатые под веб |
| `app-shots/` | Скриншоты экранов Telegram-тренажёра |

## Как править

Исходник лежит в рабочем пространстве: `02-Покерный-клуб/SYNDICATE-Академия/landing.html`.
Правки вносятся там, затем файл копируется сюда как `index.html` и пушится — GitHub Pages
подхватывает изменения за минуту-две.

Исходник OG-картинки — `og-source.html` в той же папке: открыть в браузере при окне
1200×630, снять скриншот, сохранить как `og.jpg`.
